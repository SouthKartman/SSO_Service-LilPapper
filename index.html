APPLICATION SETUP

Подключение нового клиента

Каждый сторонний сайт или сервис должен иметь собственную регистрацию в SSO. Client ID и Redirect URI должны соответствовать настройкам клиента.

Важно

Для браузерных приложений используй Authorization Code Flow с PKCE. Не помещай Client Secret в HTML или JavaScript.
